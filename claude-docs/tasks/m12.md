### Folk names

This task is numbered M12 because it was minted for Wave 12, on the owner's call (2026-10-13), by the Wave 11 review, which found that no task owned the control that calls M8.3a's `promoteFolkName`. Its subject belongs with no one milestone: it extends a component M8 builds.

**M12.1 — Promote a folk name from the ingredient form** · 1h

_Story:_ As a workspace member, I want to promote a common name to an ingredient's display name, so that the label I see matches what I actually call it.

A promote control on each row of the folk-name list in `IngredientForm` (`src/components/IngredientForm/`). It calls M8.3a's `promoteFolkName` mutation, then refreshes the form with the swapped values: the server does the swap, and the form never juggles the list itself. On a compendium row the control's confirmation says the swap is global, because every coven sees it. The component's story and doc are updated under `.claude/rules/components.md`.

_Acceptance criteria:_

- The control promotes in one round trip, with no client-side list juggling
- A compendium row's control states the swap is global before it runs
- Viewers do not see the control
- It is keyboard operable
- Axe reports nothing at 375px
- M8.3a's story acceptance test passes
