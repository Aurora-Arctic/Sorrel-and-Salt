### The compendium seed as markdown files

These ten tasks are numbered M14 because they were minted for Wave 14 on the owner's call (2026-10-23), and their subject is the compendium seed the wave finishes. The full plan, with every file and table it touches, is [`process.md`, "Compendium seed as markdown files, with a hash-gated update path, a formal-name rule and curator review (plan)"](../../design-decisions/process.md#compendium-seed-as-markdown-files-with-a-hash-gated-update-path-a-formal-name-rule-and-curator-review-plan); the decision and its reasons are [`ingredients.md`, "The compendium seed as markdown files, a formal-name rule and curator review"](../../design-decisions/ingredients.md#the-compendium-seed-as-markdown-files-a-formal-name-rule-and-curator-review).

Why they exist. The Aspen entry (live since PR #872) was thought to cite Grieve's "Poplar, Trembling" as the European _Populus tremula_ under the American _Populus tremuloides_, and carries European lore under the American tree: the common name "aspen" was taken to mean one species. (M14.12 read Grieve's page: it is headed _Populus tremuloides_. The European lore came from Kynes's joint "Aspen" entry, which heads both species.) The seed cannot correct it, because it is write-once and skips every entry already present. The owner's rule from this is that a formal name is a unique identifier and a common name never is. The seed also gives the owner no way to correct an entry by editing a file and no record of which entries a curator has reviewed. The ten tasks move the seed to one markdown file per entry, add a content hash so the seed knows when a file changed, apply a change only when the file is marked for update and no curator or editor has touched the row, enforce the formal-name rule per citation, and add a curator-reviewed mark.

**M14.33 — The Remaining Uncategorised Entries Are Sourced Through The Owner's Browser** · 30h

_Story:_ As a curator, I want the compendium entries that still have no categories sourced from the ethnographies, databases and journals that M14.31 could not reach, so that the review queue in M14.13 sees each entry with every category a source supports, at the least cost.

M14.31 swept the open English web once per entry and left 410 of 1,100 entries without categories. The sources most likely to hold their powers sit behind logins or bot checks: the Internet Archive's lending library, eHRAF World Cultures at Yale, JSTOR, and reference sites that refuse automated requests. This task reads them through the owner's own Chrome, with the Claude in Chrome extension connected to the session, so the owner's sign-ins and the sites' terms are respected and no file is copied out. It runs in stages, cheapest first, and each stage starts only when the owner says so after seeing the previous stage's count. Reading happens in the main session, one tab at a time, never in parallel lanes. Filing follows M14.31's rules in `claude-docs/compendium/compendium-seed/README.md` and the wording table in `claude-docs/compendium/category-gaps.md`; the per-entry records are kept under `.reports/` as before. The spending cap is set by the owner at the start.

_Acceptance criteria:_

- Stage A, free and no account: the pages that refused M14.31's lanes (Encyclopaedia Iranica, MDPI, SANBI, Thieme abstracts, core.ac.uk) are read for the leads already recorded; Crooke 1896, Watt's _Dictionary of the Economic Products of India_ and PROTA4U are searched for every South Asian and African entry still without categories
- Stage B, free with the owner's Internet Archive account: the lending copies of _People's Plants_, _Zulu Medicinal Plants_ and _Native American Ethnobotany_ are searched for every entry in their regions
- Stage C, free trial: a 30-day eHRAF World Cultures individual trial is searched by formal name and by common name for every entry still without categories, all regions
- Stage D, paid: one JPASS month is taken only if stages A to C leave a region with more than half its entries unsourced; its first use checks whether JPASS opens Unschuld's _Ben Cao Gang Mu_ on JSTOR. Stage E, a second month, only within the cap
- Every stage ends with the count of entries still without categories, reported to the owner, and the next stage begins only on the owner's word
- Every page read is recorded with its URL, what it printed and the result line, as M14.31's records are. A work seen for the first time goes to the owner before anything is filed from it; published ethnographies in eHRAF are approved as a class once
- A category is filed only where the source prints the formal name and a power word that maps through the wording table; new wording goes to the owner in batches and each ruling is added to the table
- Every changed approved entry file is re-marked with `seed:mark`; the seed, guard and coverage suites pass
- Docs corrected in the PR: the library table in `claude-docs/compendium/compendium-seed/README.md` lists each work read, and `claude-docs/waves/v1/wave-14.md` places the task after M14.31 and ahead of M14.13
