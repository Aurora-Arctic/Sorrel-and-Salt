**M10.29 — msw 3** · 3h

msw, the library the tests use to stand in for the network, has a 3.0.3 major. Its peers are already met (Node 22.12 or later, `graphql` 16 or later, `vite` 6 or later). The repo already uses the v3 model (`graphql.link('/api/graphql')` with `.query` and `.mutation`) and never used the removed top-level `graphql.query`, `setupWorker`, `passthrough`, `bypass` or `delay`, so the move is imports and one renamed option. `npm install --save-dev msw@^3.0.3`. `http` and `HttpResponse` now come from `msw/http`, and `graphql` and its types from `msw/graphql`; `msw/node` is unchanged. `grep -rn "from 'msw" tests` lists 19 lines in 17 files; in `tests/support/msw/graphql.ts` `graphql` and the three `GraphQL*` types move to `msw/graphql` and `HttpResponse` to `msw/http`. `onUnhandledRequest` becomes `onUnhandledFrame` with the same `'error'` value, in 12 files (`tests/support/setup-msw.ts`, `tests/support/msw/graphql.ts`, `tests/lib/mail.test.ts`, `tests/acceptance/08-email-and-admin.test.ts`, six under `tests/db/`, two under `tests/modules/identity/services/`); a comment that names it is corrected too. Docs: `claude-docs/graphql/endpoint.md` says "msw already brings in 16", which is no longer true because msw 3 declares `graphql` as a peer; `claude-docs/testing/where-tests-live.md` names the helpers and the `onUnhandledRequest: 'error'` setting. The Storybook mock (`.storybook/mock-api.ts`) moves the same way, and its worker option `onUnhandledRequest` becomes `onUnhandledFrame` too; `tests/acceptance/` no longer exists. No test logic changes, and nothing under `tests/e2e` imports msw. The plan is [`process.md`, "Dependency audit and its follow-on tasks"](../design-decisions/process.md#dependency-audit-and-its-follow-on-tasks).

**The hold was lifted on 2026-10-30.** It was for mswjs/interceptors issue #860: a passed-through raw socket wrote its first chunk twice, which broke postgres.js's SASL handshake in the database tests that mock HTTP. The issue was fixed in `@mswjs/interceptors` 0.45.9, and msw 3.0.3 now installs 0.45.10. The database test files that import msw pass under msw 3.

_Acceptance criteria:_

- `grep -rn "from 'msw'" tests` prints nothing; only `msw/http`, `msw/graphql` and `msw/node` remain
- `grep -rn onUnhandledRequest tests claude-docs/graphql claude-docs/testing` prints nothing (history under `tasks/` and `design-decisions/` keeps the old name)
- `test:coverage` passes at the threshold across all five projects, with no test logic changed beyond the import and option lines
- `graphql-pin.md` and `where-tests-live.md` match the new API
- `npm run pre-commit` passes
