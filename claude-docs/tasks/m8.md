**Amended by MB.215 (2026-10-11):** the key a promotion leaves unchanged is `identity_key`, the formal name alone, not `canonicalKey`, which MB.223 dropped ([`design-decisions/mb.215-ingredient-variants.md`](../design-decisions/mb.215-ingredient-variants.md)).

**Amended 2026-10-13 after the Wave 11 review:** nothing of this is built, and the review names its pieces. Folk names are written today only as a whole-list replace inside create and update (`src/modules/ingredients/services/ingredient-rows.ts`), so a swap needs its own write. (1) A service in the ingredients module, `promoteFolkName(session, workspaceId | null, ingredientId, folkNameId)`, doing the whole swap in one `withAudit` write. (2) The permission check follows the tier: a null `workspaceId` means a compendium row and takes `assertSiteAdmin`; otherwise `assertMembership` with the ingredient-update permission, which viewers lack. This is the convention `createReference` already has in DESIGN.md's Mutation type, where a nullable `workspaceId` means the compendium tier under the admin proof. (3) A GraphQL mutation, `promoteFolkName(workspaceId: ID, id: ID!, folkNameId: ID!): Ingredient!`. (4) The folk-name unique index is `(ingredient_id, lower(name))` on live rows, so the swap has to remove the promoted row before it writes the old display name; and a collision on the new display name, for a local row with no formal name, surfaces through the same path `refuseCollision` uses for create and update. No task mounted a control that calls this, so the UI is a new task, M12.1 (Wave 12).

_Acceptance criteria:_

- One server-side transaction; no client round-trip of the folk-name list
- The old name becomes a folk name exactly once; the promoted name leaves the folk names
- Deduplication is case-insensitive
- `identity_key` is unchanged for a row that declares a formal name
- For a row with no formal name (`none`), the key changes, and a collision surfaces as a readable error naming the other entry
- Admins may promote on compendium rows; owners and members on local rows; viewers are `Forbidden`
- The control that calls this, and its global-swap note on a compendium row, are M12.1's (Wave 12)
