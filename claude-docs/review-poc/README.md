# Local code review POC

This folder holds the records of three discovery tasks and the review process they support. Nothing in it changed the repo's code, workflows or dev container.

Read in this order:

1. `process.md`: the review process a developer follows by hand or with an agent, step by step. Start here.
2. `verify.md`: M17.31. Checks of the review tools against the repo and the container, the differences from the brief, and Drafts A to D.
3. `stacks.md`: M17.33. How stacked pull requests fit `/create-pr` and the task board, every one-PR-per-task assumption, and Drafts E to G.
4. `graphify.md`: M17.32. The Graphify setup survey, its end states, the Graphify drafts and the choice between them.
