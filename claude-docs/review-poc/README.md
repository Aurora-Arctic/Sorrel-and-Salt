# Local code review POC

This folder holds the records of three discovery tasks, the review process they support, and the plan of tasks to mint.
Read in this order:

1. `../review-workflow.md`: the review process a developer follows by hand or with an agent, step by step. Start here. `process.md` is a pointer to it.
2. `plan.md`: the six tasks to build the review setup, their order and total, what is decided and what is still unproved.
3. `verify.md`: M17.31. Checks of the review tools against the repo and the container, the differences from the brief, and the tasks it feeds.
4. `stacks.md`: M17.33. How stacked pull requests fit `/create-pr` and the task board, every one-PR-per-task assumption, and the tasks it feeds.
5. `graphify.md`: M17.32. The Graphify setup survey, its end states, the task that builds the choice.
