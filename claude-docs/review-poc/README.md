# Local code review POC

This folder holds the records of three discovery tasks, the review process they support, and the plan of tasks to mint.
Read in this order:

1. `process.md`: the review process a developer follows by hand or with an agent, step by step. Start here.
2. `plan.md`: every drafted task to mint, the order, the total, what is decided and what is still unproved. The one place you approve tasks for minting.
3. `verify.md`: M17.31. Checks of the review tools against the repo and the container, the differences from the brief, and Drafts A, B and D.
4. `stacks.md`: M17.33. How stacked pull requests fit `/create-pr` and the task board, every one-PR-per-task assumption, and Drafts C, F and G.
5. `graphify.md`: M17.32. The Graphify setup survey, its end states, the Graphify drafts and the choice between them.
