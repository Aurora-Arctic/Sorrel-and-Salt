# Set Link to the Compendium aside for v2

## Context

The owner's call (2026-10-20): linking goes one way only in v1. A coven can annotate a compendium entry and make it the coven's own (Make It Ours). The other direction, where a coven's own ingredient is linked, converted or split into compendium entries and its jars and spell layers move, is a v2 feature.

So the Link-to-the-Compendium work is extracted from M8.17's branch onto its own branch, pushed, and left for later. M8.17 keeps everything else it built (the edit dialog, Delete, the Notice restyle, the MenuButton flip, focus return, Annotate, the curator Edit, the site-wide restyle). The follow-on tasks born of Link — M12.38 and the coven-forms tasks M12.39–M12.41 — go to v2 with it (the owner, 2026-10-20).

On staging, M12.22's Similar block stays as a display of similar compendium entries; only its action, M12.21's This Is It conversion, is removed (the owner, 2026-10-20). That removal is a task of its own, built on M8.17's branch so the two PRs land in order.
