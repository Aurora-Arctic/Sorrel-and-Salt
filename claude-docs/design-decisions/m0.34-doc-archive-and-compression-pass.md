# M0.34 — Stand up the doc archive and compress the working docs

**Status:** decided · **Date:** 2026-09-09 · **Builds on:**
[m0.33-component-story-gate.md](./m0.33-component-story-gate.md),
[m0.22-gitflow-rulesets.md](./m0.22-gitflow-rulesets.md)

Two halves: create the structure every future end-of-milestone compression pass
writes into, then run that pass for M0.

---

## The archive

`claude-docs/archive/<mN>/`, one subdirectory per milestone, each file named
after the live file it came from — `archive/m0/CLAUDE.md` holds text cut from
the root `CLAUDE.md`, `archive/m0/ci.md` text cut from `claude-docs/ci.md`.
Mirroring the live layout means finding archived text needs no index.

**Write-once.** A file here is never edited again. A later pass that needs to
remove something already archived adds a new file rather than rewriting the old
one — otherwise the archive acquires the same drift problem it exists to solve.

**Transcripts are copied, not moved, and only when a subsystem is finished.**
They are append-only, so a compression pass has nothing to cut from them. No
transcript was touched by this pass; none of M0's subsystems is finished in the
"no later milestone will touch it" sense.

## What "compress" means, and what it does not

The criterion applied was **"is this statement out of date?"**, not "is this
narrative?" Two categories were deliberately left alone:

- **Forward-looking rules about M1+ work** — the services/repository boundary,
  `withAudit`, RLS, pagination, DataLoader, the whole Testing section. None of
  that code exists, but these bind future tasks. They are rules, not status
  claims. Cutting them because "the code isn't there yet" would gut the file.
- **History that is still true** — e.g. that the ports came from `resume-2026`.

What went was text asserting a present state that is no longer the present
state: "does not exist yet" about things that now exist, a Commands table
describing an "expected surface", and claims of enforcement that was never
wired up. Each removal is quoted verbatim under `archive/m0/` with the reason.

The pass also found genuine duplication: `CLAUDE.md`'s Skills section carried a
paragraph of port history that `claude-docs/agent-skills.md` already covers in
full. `CLAUDE.md` is loaded into every session, so duplication there is the
most expensive kind. It now carries the trigger table and a pointer.

## Scope calls

- **The root `README.md` was included** even though the task named only
  `CLAUDE.md` and the subsystem summaries. It had the same defect class and two
  flatly false claims (the Docker stack and the workshop described as "not
  wired up yet"; `npm run workshop` said to exit non-zero when it starts Ladle),
  plus a "Node 22 or newer" instruction that walks a reader into the exact npm
  lockfile failure M0.28 diagnosed. Same pass, one more live doc.
- **`docker.md` was not touched.** Audited and found current; everything
  verbose in it is the only written record of a real constraint.
- **`styling.md` was not touched.** Its problems are *omissions* —
  `src/scss/_layout.scss`, `_primitives.scss` and `src/app/fonts.ts` are
  undocumented, and `_typography.scss` is described by its pre-mixin shape.
  That is an expansion, the opposite shape of a compression pass. Filed
  separately, together with the equivalent gaps in `workshop.md`
  (`.ladle/layout.scss`, `.ladle/primitives.scss`, `storyOrder`,
  `previewPort`).
- **The skill files themselves were not edited.** `create-pr`,
  `create-release`, `create-main-sync` and `create-pr/reference-hotfix.md` all
  still carry "until the `gitflow` check lands (M0.17/M0.20)" hedges, and
  `create-pr` still calls the repo "pre-scaffold". Rewriting skill instructions
  has a different blast radius than editing docs. `agent-skills.md` now records
  precisely which hedges are stale and where.

## The `defaultState` finding — a doc that was right about a wrong file

`workshop.md` said `.ladle/config.mjs` sets `addons.theme.defaultState: 'auto'`.
The file reads `'dark'`. The obvious move — correct the doc — would have been
wrong:

| Task  | Value    | Documented?                                                        |
| ----- | -------- | ------------------------------------------------------------------ |
| M0.30 | `'dark'` | Yes — `m0.30-ladle-component-workshop.md`, "the app is dark-first" |
| M0.31 | `'auto'` | Yes — decision record *and* transcript, with rationale             |
| M0.32 | `'dark'` | **No** — nothing, anywhere                                         |

M0.31 changed it deliberately and rewrote the surrounding comment to explain
why. M0.32 flipped it back and left that comment standing, so `config.mjs` now
contradicts itself (lines 66–71 describe `'auto'`, line 74 sets `'dark'`). An
undocumented reversal of a documented decision, with the explanation left in
place, reads as an accidental revert.

So the doc keeps `'auto'` as the intent, states that the file currently reads
`'dark'`, and says explicitly that the code is the defect. Filed as a Bugfix;
per `CLAUDE.md` it needs a regression test, which is not this task's job.

**The general rule this establishes:** when a doc and the code disagree, the
compression pass establishes *which one is wrong* before editing either. A pass
that mechanically reconciles docs to code launders bugs into documented
behaviour.

  never existed; both now state the gap plainly.
- **`.ladle/config.mjs`'s `defaultState` regression**, above.
- **`styling.md` / `workshop.md` omissions**, above.

Two stale comment blocks were also found in non-doc files and deliberately left
alone, being outside a documentation task: `.ladle/config.mjs` lines 66–71, and
the headers of `lint-format-typecheck-check.yml` and `build-audit-check.yml`,
which still say `pr-gate.yml` and `build-image.yml` "doesn't exist yet".

## Verified

- `npm run pre-commit` — lint, `format:check`, typecheck, `check:stories` all
  pass.
- **Archive completeness, mechanically:** every content line removed from a
  live doc appears verbatim under `archive/m0/`. Checked by diffing each edited
  file against `HEAD` and grepping the removed lines against the archive — 79 of
  80 matched exactly; the one exception is a markdown table separator row whose
  dash count Prettier adjusted, which carries no content. The check needs
  whitespace normalisation, because Prettier re-pads whole table columns when
  one row is added, which a naive diff reports as removals.
- **No transcript edited:** `git diff -- claude-docs/transcripts/` is empty.
- `CLAUDE.md` is shorter on both measures: 196 → 194 lines, 19,883 → 19,723
  bytes.

## What this commits later tasks to

- Every milestone ends with this pass. The routine is named in `CLAUDE.md` →
  Conventions and specified in `claude-docs/archive/README.md`.
- A later pass adds `archive/m1/`, `archive/m2/` — it never edits `archive/m0/`.
- The first subsystem to finish gets its transcript copied into the archive,
  with a pointer left in the live file. Nothing has met that bar yet.
