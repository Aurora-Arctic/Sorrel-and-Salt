Issue #946, Wave 15 — Launch, 3h. A scoping task: it writes one decision record, mints the build tasks, edits the docs, and builds nothing. MB.176 (Bug reports, #691) is folded into it and retired, on the owner's call (2026-10-31).

## Context

The site has no way to be contacted. Two Not Started tasks each scoped part of the answer: M15.1 (a support form with question, bug and accessibility-bug kinds, reviewed by admins, with a curator view) and MB.176 (a `bug_reports` table with a reporter's own list, an admin triage page and a prefilled GitHub Create Issue button). One table and one form serve both; the owner chose to merge MB.176's mechanisms into M15.1's design and retire #691.

Decisions the owner made in this session (2026-10-31), recorded in the record with their reasons:

| Decision                     | Answer                                                                                                                                                                                                                                                                                                                                                                                     |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Who can submit               | Signed-in, verified accounts only (a viewer and an account in no coven included). A signed-out visitor sees a Sign In link in the form's place. Reason: `withAudit` refuses a write with no session, no system actor exists, and the app has no rate limiter outside Better Auth's own.                                                                                                    |

A `data` kind (GDPR) is left out until the GDPR scoping task chooses.                                                                                                                                                                                                                           |

| Replies                      | Rows of their own table, shown on the sender's list at `/account/support`; a short mail says a reply is waiting and links there (the reply text is not mailed).                                                                                                                                                                                                                            |
| Curator                      | Reads requests marked `curatorVisible` or assigned to them; replies to and resolves only what is assigned to them; never reassigns or changes visibility. Same `/admin/support` page, filtered in SQL.                                                                                                                                                                                     |
| Module                       | A new sixth module, `support`.                                                                                                                                                                                                                                                                                                                                                             |

| Time-out (owner, 2026-10-31) | An admin (not a curator) can time a sender out: a `support_timeouts` row with `until` and a note; `sendSupportRequest` refuses while one is active, with an explaining error naming the end; an admin can lift it early.
