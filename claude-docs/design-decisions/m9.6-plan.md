## What M9.6 builds

1. **A count of the coven's list.** `findWorkspaceIngredientCount(membership, filter, start)` in the repository is a twin of `findCompendiumCount`, over `and(list.arms, workspaceListScope(...))`. The service `countWorkspaceIngredients(session, workspaceId, filter, start)` asserts the same `ingredient:['read']` permission as the list and is **not cached**, because the data is the coven's (rule 6). Nothing in GraphQL changes: only the server-rendered page counts.

2. **The coven's reads**, in `src/app/(shell)/coven/[slug]/ingredients/reads.ts`. They are wrapped in React `cache()` and keyed by plain strings, as `compendium-reads.ts` is:
   - one page of `CARD_PAGE_SIZE` with its count, through `readNumberedPage`;
   - the page's variants and categories, with the coven's `workspaceId`;
   - every jar on the page in one `stockOf` call;
   - the facets.

   Each edge's `cupboardEntry` gives the card's kind, Annotated and Retired marks, and the coven's label (`applyCupboardEntry`).

3. **The filter gets a coven mode.** `CompendiumList/filter.tsx` is a client component, so its props must be plain data rather than functions. Today it chooses between the admin and public lists with `audience: 'admin' | 'public'`. This adds `audience: 'coven'` with `covenSlug` and `workspaceId` props. In coven mode the filter:
   - reads and writes addresses through `COVEN_PARAMS`, at `/coven/<slug>/ingredients`;
   - carries `source`, `inStock` and `lowStockOnly` in `panelOf`, `NO_FACETS`, `heldFilter` and `hrefFor`, so FacetPanel's Source, In Stock and Low Stock controls appear;
   - fetches live facet counts with a new coven version of `useLiveFacets` (a `workspaceIngredientFacets` query mapped through `covenFacetCounts`);
   - opens a picked type-ahead match at `/coven/<slug>/ingredients/<id>`.

   `compendiumHref` gets a coven twin, `covenIngredientsHref`, beside it in `href.ts`.

4. **Type-ahead from the cupboard.** `IngredientSearchBox` and `IngredientSearchForm` take an optional `workspaceId`. When it's set, the box queries `workspaceIngredients(workspaceId:, query:, first:)` instead of `compendium`, and shows the coven's label where one is set. The match shape stays the same. Run `npm run codegen` and commit its output. Suggestions never come from another coven, and that includes the suggested names themselves (CLAUDE.md).

5. **The search sentence covers the coven filters.** `buildSearchSentence` gains clauses for Source, In Stock and Low Stock Only (`sentence.ts` and `types.ts`), and the coven filter uses the existing `noun` option.

6. **`CovenCards`**, a new component (directory, Ladle story, doc, test) and twin of `CompendiumCards`:
   - `IngredientSearch shape="cards"` with the coven filter;
   - `IngredientCardList label="Ingredients" density="compact"`;
   - one `IngredientCard` per entry, with `kind`, `annotated`, `retired` and the coven's label, linking to `/coven/<slug>/ingredients/<id>`;
   - **`JarLines`** in the card's `children` slot: one list item per jar, "icon · form · quantity unit", with `StockBadge` last. Forms go through `formLabel`, and the icon is the jar's variant form looked up in `readFormIcons`.

   The `actions` slot stays empty: M8.17 (Edit) and M9.10 (Delete) fill it. An empty list shows plain text for now, since M9.11 owns the empty state.

7. **The page** `src/app/(shell)/coven/[slug]/ingredients/page.tsx`:
   - calls `requireCovenMembership(slug)`, so a non-member gets a 404;
   - reads its filter from `COVEN_PARAMS.read`, its cursors from `readPageCursors`, then calls the reads and renders `PageHeader` and `CovenCards`;
   - sets `metadata.title` to "Ingredients".

8. **The Compact switch.** It is on by default and remembered on this computer:
   - The page renders the list `data-density="compact"`, so a first visit, and a visit with script off, show compact.
   - A fourth script in `src/app/pre-paint-scripts.tsx` reads `localStorage['card-density']`. When the stored choice is regular, it sets `data-card-density="regular"` on `<html>` before the first paint, so the compact look never flashes.
   - The compact selectors in `IngredientCardList/index.scss` and `IngredientCard/index.scss` gain `:not(:root[data-card-density='regular'] *)`, a Baseline Widely Available selector. Card lists that don't ask for compact are untouched.
   - The switch, a `SwitchField` in the filter row inside the `search` landmark (story 12 counts editing controls outside it), sets the attribute and the stored value. It reads its starting state from the attribute through `useSyncExternalStore`, so the server and browser renders agree.
   - `tests/app/pre-paint-scripts.test.tsx` expects four scripts.

9. **Navigation and the coven home.**
   - `covenSections` (`src/components/CovenNav/sections.ts`) gains an Ingredients row for every role.
   - The coven home's Contents section shows for every role, viewers included, with an Ingredients link. Members stays conditional, and the MB.121 comment in `src/app/(shell)/coven/[slug]/page.tsx` is corrected.

10. **Stories and the gate spec.**
