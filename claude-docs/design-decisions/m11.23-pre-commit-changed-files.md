# Pre-commit on changed files only

**Status:** decided and built. Only the decisions, the reasons and what they rule out are kept here.

## Why lint-staged, and not another option

These figures were checked against the npm registry on 2026-10-16. The weekly download counts cover 2026-10-06 to 2026-10-12.

| Option                                                                                                                                            | What it costs                                                                                                                                              | What it buys                                                                                                                                                                                                          | What it lacks                                                                                                                                                                                                                                                                             |
| ------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **No new package**: a script in `scripts/` that lists the files with `git diff` and sorts them with `picomatch`, which is already a devDependency | No dependency                                                                                                                                              | Full control                                                                                                                                                                                                          | It would check the **working-tree** copy of a staged file, not the copy being committed. Hiding unstaged edits safely while the checks run (and putting them back after a failure or Ctrl-C) is the subtle part. We would be writing and maintaining that ourselves, or going without it. |
| **The existing `pre-commit` package**                                                                                                             | No dependency                                                                                                                                              | It already installs the hook                                                                                                                                                                                          | It only runs npm scripts by name. It can't hand them a list of files, so on its own it can't narrow anything.                                                                                                                                                                             |
| **lint-staged 17.6.0** (30.1M downloads a week, MIT)                                                                                              | 168 KB and three dependencies. Two of them (`picomatch`, `tinyexec`) are already in `node_modules`, so in practice it adds `string-argv` and nothing else. | It hides partially staged edits by default (`--no-hide-partially-staged` turns that off). `--diff=HEAD` gives the by-hand run. A function entry runs a command once with no file list, which is what typecheck needs. | Nothing this task needs                                                                                                                                                                                                                                                                   |
| **nano-staged 1.0.2** (136k a week)                                                                                                               | 53 KB, no dependencies                                                                                                                                     | It has `--diff` and `--unstaged`                                                                                                                                                                                      | Its README says nothing about hiding unstaged edits. Its function entries build the command string by joining the file names, so quoting the names is our job. It is about 1/200th as widely used.                                                                                        |
| **lefthook 2.2.2** (6.0M a week)                                                                                                                  | One Go binary per platform, installed through optionalDependencies. It would also replace the `pre-commit` package.                                        | Hook manager and file narrowing in one YAML file                                                                                                                                                                      | It is a bigger change than asked for: the hook installer changes in every checkout and in the devcontainer. I haven't confirmed whether it hides unstaged edits the way lint-staged does.                                                                                                 |

**Recommendation: lint-staged.** It is the one option that checks the copy being committed, the hiding is the part most likely to go wrong in a script we write ourselves, and its real cost is one small extra package (memory: prefer the standard tool). The `pre-commit` package stays as the hook installer, so nothing changes in how hooks get set up.
