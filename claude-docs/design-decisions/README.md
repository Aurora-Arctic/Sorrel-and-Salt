# Design decisions

One record per task where a choice needed explaining — what was decided, why,
and what it rules out. Named `<mN.n>-<slug>.md`.

**M0's records have been archived** under `../archive/m0/design-decisions/`, and
are not required reading. Records move there once their milestone closes — and
before they do, every decision and constraint they hold is written into the live
summary that depends on it, so no live doc links into the archive. If you find
yourself needing an archived record to understand the system, the live summary
is missing something: fix the summary.

This directory holds the current milestone's records and is empty between
milestones. Write a new record here when a task's choice would otherwise get
re-argued later; link it from the subsystem summary that depends on it.
