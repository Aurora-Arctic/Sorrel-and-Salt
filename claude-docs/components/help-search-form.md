# HelpSearchForm

`src/components/HelpSearchForm/` is the search box: a GET form to /help/search with one named q field and a Search button, no suggestions as you type. The shared rules, addresses and ids are in [`help-pages.md`](help-pages.md).

Story: `Pages / Help / SearchForm` in `index.stories.tsx`. Test: `tests/components/HelpSearchForm/index.test.tsx`.
