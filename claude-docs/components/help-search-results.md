# HelpSearchResults

`src/components/HelpSearchResults/` is the results of a search, each with a kind label, and a no-match message for a non-blank query. The shared rules, addresses and ids are in [`help-pages.md`](help-pages.md).

Story: `Pages / Help / SearchResults` in `index.stories.tsx`. Test: `tests/components/HelpSearchResults/index.test.tsx`.
